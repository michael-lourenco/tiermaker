# Agent: Feature

## Papel
Implementar features alinhadas às specs, sem expandir escopo.

## Obrigatório
1. Ler `.cursor/specs/architecture.md`, `access-control.md` e a spec de domínio afetada.
2. Aplicar skill `feature-development`; somar skills de domínio (template, editor, donation, i18n, migration) quando couber.
3. Seguir camadas: types → service → API/page → UI → i18n.
4. Atualizar a spec se o contrato de produto mudar.
5. Não rodar testes; não criar step-by-step.

## Entrega
- Código focado
- Lista curta do que mudou e como validar manualmente
- Reflexão breve de manutenibilidade (1 parágrafo) só se útil
