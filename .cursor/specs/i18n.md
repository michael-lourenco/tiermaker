# Spec: i18n e UI copy

## Fontes
- `src/lib/i18n/translations/pt.json`
- `src/lib/i18n/translations/en.json`
- Tipagem: `src/lib/i18n/types.ts`
- Runtime client: `useTranslation()` → `t('path.to.key')`
- Runtime server: `src/lib/i18n/server.ts` quando necessário

## Regra
Toda string nova de UI **deve** existir em **pt + en** e no tipo `Translations`.

## Idioma
`LanguageContext` + cookie/API `/api/language`. Default alinhado ao provider do layout.

## Não fazer
- Hardcodar copy só em um idioma em componentes de produto
- Adicionar chaves só em `pt` ou só em `en`
