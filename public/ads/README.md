# Placeholder Images para Espaços de Publicidade

Este diretório contém imagens placeholder SVG que podem ser usadas como publicidades manuais para testar a aparência dos espaços de publicidade no site.

## Imagens Disponíveis

### Desktop
- **placeholder-728x90.svg** - Leaderboard (728 × 90)
  - Uso: Banners horizontais no topo ou rodapé
  - URL: `/ads/placeholder-728x90.svg`

- **placeholder-970x250.svg** - Billboard (970 × 250)
  - Uso: Banners grandes no topo da página
  - URL: `/ads/placeholder-970x250.svg`

- **placeholder-300x250.svg** - Medium Rectangle (300 × 250)
  - Uso: Sidebar, entre conteúdo
  - URL: `/ads/placeholder-300x250.svg`

- **placeholder-300x600.svg** - Half Page (300 × 600)
  - Uso: Sidebar fixa, anúncios verticais
  - URL: `/ads/placeholder-300x600.svg`

### Mobile
- **placeholder-320x50.svg** - Mobile Banner (320 × 50)
  - Uso: Banners pequenos no mobile
  - URL: `/ads/placeholder-320x50.svg`

- **placeholder-320x100.svg** - Large Mobile Banner (320 × 100)
  - Uso: Banners médios no mobile
  - URL: `/ads/placeholder-320x100.svg`

## Como Usar

1. Acesse `/admin/ads` no seu site
2. Crie um novo espaço de publicidade
3. Selecione o tipo "Manual"
4. Use uma das URLs acima como "Imagem"
5. (Opcional) Adicione uma URL de destino para testar cliques

## Exemplo de Configuração

**Banner Topo Homepage:**
- Nome: Banner Topo Homepage
- Posição: header-top
- Tipo: Manual
- Imagem: `/ads/placeholder-728x90.svg`
- URL de Destino: `https://exemplo.com` (opcional)

**Sidebar Desktop:**
- Nome: Sidebar Direita
- Posição: sidebar-right
- Tipo: Manual
- Imagem: `/ads/placeholder-300x250.svg`
- URL de Destino: `https://exemplo.com` (opcional)

## Cores dos Placeholders

Cada placeholder tem uma cor diferente para facilitar a identificação:
- 🔵 Azul (728x90) - Leaderboard
- 🟢 Verde (970x250) - Billboard
- 🟠 Laranja (300x250) - Medium Rectangle
- 🟣 Roxo (300x600) - Half Page
- 🔴 Vermelho (320x50) - Mobile Banner
- 🌸 Rosa (320x100) - Large Mobile Banner
